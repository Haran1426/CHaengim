# 챙김

마감일과 준비물, 진행 단계를 함께 관리하는 Flutter 앱입니다. Android를 우선 대상으로 개발합니다.

## 현재 구현

- 홈: 이번 주 마감 표시·날짜별 조회, 기한순 미완료 일정, 준비물 빠른 체크, 빈 상태의 종류별 일정 추가
- 일정 등록·수정·삭제: 제목, 날짜, 선택 시간, 카테고리, 체크리스트, 메모, 참고 링크
- 상세: 준비물 체크 및 진행 단계 직접 변경
- 일정 목록: 검색과 진행 중·전체·완료 필터
- 기기 로컬 저장 및 저장 오류 처리
- 한국어 날짜·시간 선택 화면
- Noto Sans KR 글꼴과 종이빛·초록 테마, 우선순위 홈과 준비물 빠른 체크
- 결과 발표·추가 서류 제출 등의 후속 일정 연결
- 카테고리 및 7일 이내 기간 필터
- Android 소형(1건)·중형(2~3건) 홈 화면 위젯, 상세·등록 진입 및 저장 후 동기화
- 일정별 당일·1·3·7일 전 사전 알림, 시각 선택, 권한·전체 설정·테스트 알림
- 앱·Android 위젯 테마: 무료 숲·모래, 플러스 바다·라일락·살구 미리보기
- 챙김 플러스: 광고 제거와 꾸미기 전용 일회성 상품 화면, 구매·복원 SDK 연결 구조
- 마이 하단 테스트 배너 광고. 실광고·실결제는 계정 연결 전 비활성

시간 미지정 일정은 선택한 날짜의 23:59로 저장하며, 화면에는 날짜만 표시합니다. D-day는 달력 날짜 기준입니다. 기한 경과 또는 준비물 완료로 일정을 자동 완료하지 않습니다.

참고 링크는 현재 텍스트 선택·복사를 지원합니다. 클라우드 백업은 아직 구현하지 않았습니다. 앱 삭제 시 데이터가 사라질 수 있습니다.

위젯 추가: 앱 홈 우측 위 위젯 아이콘 또는 마이 → 홈 화면 위젯 → 크기 선택 → 홈 화면에 추가. 런처가 추가 요청을 지원하지 않으면 홈 화면을 길게 눌러 위젯 목록에서 챙김을 선택합니다.

알림: 일정 등록·수정에서 날짜와 시각을 선택하고, 마이 → 마감 알림에서 권한과 전체 켜짐 상태를 확인합니다. 일반 예약이므로 정시 도착을 보장하지 않으며 절전 상태에서 지연될 수 있습니다. [알림 동작과 검수](docs/reminders.md)를 참고하세요.

앱에서 변경하면 바로 갱신하며, Android에도 30분 간격의 갱신을 요청합니다. 절전·강제 종료·런처 정책에 따라 표시 갱신이 지연될 수 있습니다. iOS 위젯은 지원하지 않습니다.

## 실행 및 확인

Flutter **3.50.0 이상**과 Dart **3.14.0 이상**을 사용합니다. Material UI와 한국어 날짜·시간 선택은 별도 `material_ui` 패키지를 사용합니다.

Flutter SDK를 PATH에 등록한 터미널에서:

```sh
flutter pub get
flutter analyze
flutter test
flutter run
```

Android 빌드 환경과 Windows 설정은 [개발 환경 설정](docs/development-setup.md)을 참고하세요.

홈·일정·마이 화면에서 아래로 당겨 새로고침합니다. 다시 불러오기에 실패하면 마지막으로 확인한 일정을 표시하고 재시도를 안내합니다. [지연·새로고침 처리](docs/async-reliability.md)에 동시 요청과 시간 초과 처리 범위를 정리했습니다.

출시는 Google Play를 먼저 준비합니다. 정식 패키지 ID·업로드 서명·개인정보 및 SDK 신고 등 남은 작업은 [Google Play 출시 준비](docs/google-play-launch.md)를 참고하세요.

계정 심사 후 결제 연결은 [Google Play 결제 순서](docs/play-billing-setup.md)를 따라 진행합니다. `dart tool/build_play_store.dart --check`로 로컬 설정을 검사할 수 있습니다. GitHub Actions는 Flutter 3.50 코드 검사·테스트·임시 서명 AAB 빌드를 수행하며 스토어에 자동 제출하지 않습니다.

## 코드 구조

- `lib/models/`: 일정과 준비물 데이터, 진행 단계, D-day 계산
- `lib/data/`: 기기 저장과 화면 상태 관리
- `lib/screens/`: 홈, 목록, 마이, 등록·수정, 상세 화면
- `test/`: 저장 복원·실패 처리와 핵심 화면 흐름 검증

짧은 학습 메모는 [개발하면서 배우기](docs/learning-notes.md)를 참고하세요.

유료화 범위와 스토어·광고 연결 절차는 [플러스와 광고](docs/monetization.md)에 정리했습니다. 모든 일정 관리 기능은 무료로 유지합니다.

레퍼런스·색상·화면 구조·위젯 동작과 검수용 앱 빌드법은 [디자인 방향](docs/design-direction.md)에 정리했습니다.

로컬 저장은 Flutter의 [shared_preferences](https://pub.dev/packages/shared_preferences) 패키지의 비동기 API를 사용합니다.
